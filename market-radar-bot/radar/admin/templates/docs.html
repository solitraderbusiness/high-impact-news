What is Market Radar Bot?

Market Radar Bot is a production-grade system for monitoring market-moving news and sending timely alerts via Telegram. It watches influential people, institutions, central banks, and economic events, detects relevant news using rules + AI, scores severity (0-100), and sends formatted alerts.

How It Works

1

Collect

Bot polls configured sources (RSS feeds, websites, Telegram channels, X/Twitter accounts) every 60 seconds for new content.

2

Match

Each news item is matched against Watch Items using keywords and entity matching. The system identifies which entities (people, institutions, events) are mentioned.

3

Analyze

AI (via OpenRouter) analyzes matched items for market relevance, filters out noise (political gossip, social issues), and generates trading insights.

4

Score

Each detection gets a severity score (0-100) based on source reliability, recency, keywords, and AI confidence.

5

Alert

High-severity items (70+) are translated to Persian and sent to Telegram with trade bias, affected assets, and key levels.

Severity Scoring (0-100)

Each detection receives a composite score based on multiple factors:

Factor Points Description
Match Confidence 0-40 How well keywords/entities matched
Source Tier 0-20 PRIMARY=20, SECONDARY=10, SOCIAL=0
Recency 0-15 Newer content scores higher
High-Impact Keywords 0-25 "rate hike", "sanctions", "war", "emergency"
70+ Immediate Alert
90+ Bypasses Cooldown
30-69 Included in Digest

Admin Panel Guide

Watch Items

Configure what entities to monitor. Each watch item has:

  • Keywords: Words to match (case-insensitive)
  • Entities: Exact names to match (case-sensitive)
  • Assets Affected: What trades when this triggers
  • Cooldown: Minimum time between alerts

Sources

Configure where to get news. Each source has:

  • URL: Feed URL, web page, or @username for X
  • Type: RSS, Web, Telegram, or Twitter
  • Tier: Affects severity scoring
  • Global: Applies to all watch items

Events

View all collected news items with:

  • Detection status and severity score
  • Test send button to preview alerts
  • Source attribution and timestamps

Settings

Configure system behavior:

  • Telegram: Bot token and chat ID
  • Thresholds: When to send alerts
  • AI Models: Which LLM for analysis vs translation
  • Schedules: Daily summary and sentiment reports

Technical Information

Stack

  • Backend: Python 3.11+ / FastAPI
  • Database: SQLite (dev) / PostgreSQL (prod)
  • ORM: SQLAlchemy 2.0
  • Scheduler: APScheduler
  • AI: OpenRouter API (Claude/GPT)

Server

  • User: radarbot
  • Service: systemctl (radarbot.service)
  • Logs: journalctl -u radarbot -f
  • Admin: Port 8000
