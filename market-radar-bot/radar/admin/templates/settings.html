🚀 Deploy Updates

Pull latest code from git and restart the service.

⚠️ First-time setup required:
  1. SSH to your server as radarbot
  2. Create ~/deploy.sh with this content: 
    #!/bin/bash
cd ~/high-impact-news
git pull origin claude/add-admin-pagination-Ua4Cz
cd market-radar-bot
source venv/bin/activate
pip install -e . 2>/dev/null
sudo systemctl restart market-radar
echo "Deployed at $(date)"
  3. Make it executable: chmod +x ~/deploy.sh
  4. Allow passwordless restart: sudo visudo and add:
    radarbot ALL=(ALL) NOPASSWD: /bin/systemctl restart market-radar
