Deploy Updates

Pull latest code from git and restart the service.

First-time setup required:

The deploy.sh script is included in the project. You just need to configure sudoers for passwordless service restart:

# SSH to server and run:
sudo visudo -f /etc/sudoers.d/radarbot

# Add this line (change 'market-radar' if your service name differs):
radarbot ALL=(ALL) NOPASSWD: /bin/systemctl restart market-radar

After this, the Deploy button will work automatically.
